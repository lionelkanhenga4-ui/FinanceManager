# Finance Manager Website

This is a browser-based version of the Android Finance Manager app, connected to Supabase for authentication and transaction storage.

## Features

- Login and sign-up flow with Supabase Auth
- Dashboard overview with balance, income, and expenses
- Recent transactions list
- Transaction history with filters
- Analytics view with category breakdown
- Add and delete transactions from Supabase
- Local fallback state when not signed in

## Supabase setup

The website is configured using the project URL and anon key in [website/supabase-config.js](supabase-config.js).

Create the table in your Supabase SQL editor:

```sql
create table public.transactions (
  id bigint generated by default as identity primary key,
  title text not null,
  amount numeric(12,2) not null default 0,
  type text not null check (type in ('income', 'expense')),
  category_name text default 'Other',
  account_id text default 'Checking',
  user_id uuid not null references auth.users(id) on delete cascade,
  date timestamptz not null default now()
);

alter table public.transactions enable row level security;

create policy "Users can view their own transactions"
on public.transactions
for select
using (auth.uid() = user_id);

create policy "Users can insert their own transactions"
on public.transactions
for insert
with check (auth.uid() = user_id);

create policy "Users can update their own transactions"
on public.transactions
for update
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

create policy "Users can delete their own transactions"
on public.transactions
for delete
using (auth.uid() = user_id);
```

If you want to use your own project, replace the URL and anon key in [website/supabase-config.js](supabase-config.js).
